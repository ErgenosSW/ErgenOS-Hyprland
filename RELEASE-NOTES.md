# ErgenOS Hyprland 0.1.0-33 preview

Optional tiled session alongside GNOME, with coordinated styling, desktop
controls, clipboard history and session supervision. This is configuration and
integration tooling, not a fork of the Hyprland compositor.

Requires the separately packaged ergenos-waybar helper and the Hyprland 0.56.x
series declared by the recipe. Attach both signed packages and signatures.

This is an experimental preview. Fresh-account screenshot/notification follow-up,
screen-sharing and external-monitor/hardware acceptance remain incomplete.
Artwork provenance gaps are documented in THIRD_PARTY.md. Review that file and
packages/ergenos-hyprland/RELEASE-CHECKLIST.md before publishing artifacts.
The build workflow leaves the release as a draft for maintainer review.
